## About

The Student Record System is a record-keeping application for maintaining student academic information — profiles, course enrollment, attendance, grades, and fee status — with role-based access for Students, Faculty, and Administrators.

## Features

- **Authentication & Roles** — secure login with role-based access control (Student / Faculty / Administrator); account lockout after repeated failed attempts; password reset via OTP.
- **Student Profiles** — create and maintain student records (personal details, program, branch, semester); students can update permitted fields subject to admin verification; full change history.
- **Course & Enrollment** — define courses with credits and prerequisites; students enroll within configured windows and credit limits; faculty can view course rosters.
- **Attendance** — faculty record session-wise attendance; automatic percentage calculation; alerts when attendance drops below the configured threshold.
- **Grades & Transcripts** — faculty submit marks, admins approve and publish results; automatic GPA/CGPA calculation; downloadable transcripts; grade-review requests within a set window.
- **Fee Management** — automatic fee invoicing per semester; payment tracking; reminders for pending dues; registration holds for excess outstanding dues.
- **Reporting** — class/course performance reports, data export, and dashboard summaries for administrators.
- **Administration & Audit** — role/permission management, record archival, and a searchable audit log of all administrative actions.
